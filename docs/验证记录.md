## 这轮被测试抓出来的真 bug

记下来，免得后来人以为这些数是天生对的。

| 症状 | 根因 | 定位方式 |
| --- | --- | --- |
| 金星距角 176.9°（应 <46°） | 行星 `eq.lon` 存的是日心黄经，却拿去减太阳地心黄经 | DE440s 位置比对 |
| 月龄出现负数与 null | 回溯找朔时用 `e>180` 定位，亏凸月当天就命中 | 月相序列连续性 |
| 望月日期一次算出两个 | 相位穿越判据没排除 360→0 跳变，方向也写反 | 朔望与 DE440s 比对 |
| HSL 降绿饱和毫无反应 | `bandWeight` 把带心与 180° 外算反，权重在带心处为 0 | 分色单通道断言 |
| 星图上星点完全不画 | `S.stride` 取成 undefined → 半径 NaN；`meta.stride` 才是真位置 | 画布亮像素统计 |
| 专名糊成一片 | 同上，星等门槛判断失效，298 个名字全画 | 截图肉眼复核 |
| 磨皮把硬边一起抹平 | 边缘保护用固定除数 96，低对比片子不保护、高对比过保护 | 合成硬边梯度保留率 |
| 去雾几乎无变化 | 用一个标量大气亮度归一，应逐通道 `min(I_c/A_c)` | 人造雾 RMSE |
| 五个视图里两个白屏 | `card(opts, kids)` 把数组当一个孩子传给 `appendChild` | 浏览器实跑 + 堆栈上屏 |
| 站点表 20 多个点经纬颠倒 | 手写数据无校验 | 加了境内框与越界自检 |
