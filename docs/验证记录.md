联网对照（`LF_ONLINE=1`）另与 api.sunrise-sunset.org（NOAA 算法实现）比了北京、新加坡、特罗姆瑟、乌斯怀亚四个纬度带在冬至日的日出日落与民用晨昏，容差 4–5 分钟内全通过。

## 影像算子核对（tests/imaging.test.mjs）

65 项断言全通过，全部用合成图，不依赖浏览器。

| 算子 | 判据 | 实测 |
| --- | --- | --- |
| 空参数恒等 | `toneLUT({})` 与 `renderPipeline(src, {})` 必须不动图 | 最大偏差 0 / 2 级（后者受 8 位量化） |
| 曝光 | +1 EV 线性亮度 ×2、−1 EV ÷2 | 1.8873× / 0.5387×（容差 0.12 / 0.08，差在 8 位量化与 sRGB 端点） |
| 高低频磨皮 | 平涂噪声要降、硬边要留 | 噪声标准差比 0.24，硬边梯度保留 0.8954 |
| 肤色掩膜 | 合成脸椭圆内均值高、椭圆外近 0 | 内 0.8727 / 外 0.0000 |
| 天空掩膜 | 上部高、地面 0 | 上 0.6911 / 地 0.0000（启发式初值，界面留补画笔） |
| 去雾 | 人造雾（t=0.42）复原后与无雾原图 RMSE 比 | 0.4482，且局部标准差从 7.5 抬到 26.3 |
| 自动水平 | 倾斜 7° 的强边界 | 检出 7.00°；纯水平线场景 −0.50° |
| 几何 | 旋转 0 恒等、+90 后 −90 回原 | 中心区最大差 < 8 亮度 |
| 控制点 | 圈内亮、圈外不动 | 圈内 112→149，圈外 148→148 |
| 盒式模糊 | 平场不动、冲激响应上下与左右对称、能量守恒 | 平场最大偏离 0；对称差 0；能量 1.0000 |
| 纹理 / 锐化 | 平场拉满不许变亮，但真高频处必须有反应 | 平场 128 保持 128.0000；条纹图最大改动 25 |
| 裁剪 | 输出尺寸就是裁剪框、不许有整行纯黑 | 400×300 取 16:9 地标不位移；取 3:2 纯黑行 0 |
| 颗粒 | 同种子逐字节一致、换种子不同、强度单调 | 通过 |
| `.cube` | 与整条预览链路逐色比对 | 最大偏差 0.0000 |
| 性能 | 640×480 全算子一次渲染 | 288 ms（分段：去雾 66 · 分色 37 · 细节 23 · 人像 134） |

## 界面回归（tools/shot.mjs）

界面这条用无头 Electron 自跑：加载 `file://`（与"双击就能用"同一条承诺），改 `nativeTheme.themeSource` 来验"跟随系统"这条路，逐组截图并探测四件事——兜底卡、控制台报错、画布亮像素、横向溢出。

| 组 | 数量 | 覆盖 |
| --- | --- | --- |
| 五个视图 × 明暗 × 1440 | 10 | 基础渲染；星野两组各在画布上扫 30 个悬停点，走 hitTest 与 tooltip 这条纯鼠标路径 |
| 首页、星图、精修 × 412 | 3 | 窄屏与断点，判横向溢出 |
| 路书 × 900 | 1 | 中屏三段式退化 |
| 精修拖放导入 | 1 | 页面内现画样片 → `DataTransfer` → `drop` → FileReader → Image → 渲染，并断言改配方前后画布像素哈希必须不同 |
| 星野穹顶 / 取景 × 明暗 | 2 | 两套投影各画一次 |

合计 **17 组，失败 0 组**。两处口径说明：投影模式必须每组前显式设定，无头窗口的 `localStorage` 会跨次运行留存，不设定就会出现"上一轮存了 frame，这一轮的穹顶图悄悄变成取景图"这种假通过；截图落 `$TMPDIR/lf-shots`，`docs/screens/` 里那套编号名是它们缩半得来的。

## 被测试与复检抓出来的真 bug

记下来，免得后来人以为这些数是天生对的。前 13 条是首版开发期，其余是发布前两轮复检抓出的。

| 症状 | 根因 | 定位方式 |
| --- | --- | --- |
| 金星距角 176.9°（应 <46°） | 行星 `eq.lon` 存的是日心黄经，却拿去减太阳地心黄经 | DE440s 位置比对 |
| 月龄出现负数与 null | 回溯找朔时用 `e>180` 定位，亏凸月当天就命中 | 月相序列连续性 |
| 望月日期一次算出两个 | 相位穿越判据没排除 360→0 跳变，方向也写反 | 朔望与 DE440s 比对 |
| HSL 降绿饱和毫无反应 | `bandWeight` 把带心与 180° 外算反，权重在带心处为 0 | 分色单通道断言 |
| 星图上星点完全不画 | `S.stride` 取成 undefined → 半径 NaN；`meta.stride` 才是真位置 | 画布亮像素统计 |
| 专名糊成一片 | 同上，星等门槛判断失效，298 个名字全画 | 截图肉眼复核 |
| 磨皮把硬边一起抹平 | 边缘保护用固定除数 96，低对比片子不保护、高对比过保护 | 合成硬边梯度保留率 |
| 去雾几乎无变化 | 用一个标量大气亮度归一，应逐通道 `min(I_c/A_c)` | 人造雾 RMSE |
| 五个视图里两个白屏 | `card(opts, kids)` 把数组当一个孩子传给 `appendChild` | 浏览器实跑 + 堆栈上屏 |
| 站点表 20 多个点经纬颠倒 | 手写数据无校验 | 加了境内框与越界自检，并补一条测试当消费者 |
| 点深色按钮界面不动 | 启动时就把 `auto` 覆盖成 light/dark，"跟随系统"这条路从没走过 | 无头回归切系统明暗偏好后比对 `data-theme` |
| 首页光段刻度互相压字 | 标签按百分比绝对定位，字宽不参与判定 | 1440 与 412 两套截图肉眼复核 |
| 取景投影顶端一圈糊字 | 方位线在天顶收敛，标签全画同一处又被上边缘裁掉 | 取景组截图 + 改挂到画面中线处 |
| 月末那晚整晚算出零采样 | `nightPlan` 的"次日"用 transit+12h 推，年月从 UTC 取、日从加过时区的那一刻取，两套坐标系拼一个日期 | 40 站 × 12 个月末的穷举断言 |
| 选任何裁剪比例画面整体平移 | `transform` 收到的已经是裁剪后缓冲，却又把 `crop.x/y` 加回采样中心 | 地标块位置断言 |
| 裁剪导出底部一条纯黑带 | `cropRegion` 的缓冲是 `x1-x0`，调用方自己 `round(crop.w)`，差出 1 行 → 双线性读到数组外 → NaN → 0 | 整行纯黑计数断言 |
| 纹理与锐化其实是亮度滑杆 | 高频项拿 8 位 sRGB 减线性 0..1，留下约 +73 的常数偏置，平场 128 被拉到 208 | 平场不变性断言 |
| 模糊核不对称、总能量 +1.5% | 乒乓缓冲的交换式只在第一趟成立，第二趟起纵向那遍就地读写自己 | 冲激响应对称性与能量断言 |
| 轮廓打点一侧被叠加 | `warpPoint(img, img, …)` 行主序就地读写，中心左上侧读到已改写像素 | 与"先快照再写"的参考结果比对 + 对称源图断言 |
| 夏夜把指针移到银心就每帧抛 TypeError | 银心标记只带屏幕坐标进 `bodies`，`hitTest` 仍当它是可悬停天体 | 回归里加的 30 点悬停扫描 |
| 工作台每渲染一次多一个 resize 监听 | 只有 sky/retouch 实现了 `_cleanup`，home 注册 window 级监听却没摘 | 代码复核（泄漏会钉住整批 DOM 节点） |
| 播放中碰任一滑杆，时间轴冻住但按钮还显示暂停 | 播放帧与重绘帧共用一个 `raf` 句柄，`invalidate` 把播放那一帧 cancel 了 | 代码复核 |
| 中途关页面后下次打开自动开播 | `playing` 是运行态却被持久化，`_cleanup` 只改内存不落盘 | 代码复核 |
| 手改进度坐标刷新即丢、侧栏下拉空白 | `siteFromKey('custom')` 找不到就退回 `list[0]`，而自定义站点从没入库 | 代码复核 + 存档字段补 `custom` |
| 跨年档期的"最好那天"时刻错一天到几十天 | 行里只存 `M/D`，年份现取当年 | 代码复核；改成行内带 y/m/d |
| 导入一个尺寸读不出的文件会让整批静默卡死 | `img.onload` 不判 `naturalWidth`，`makeThumb` 的画布高度算成 NaN 抛异常，`pending` 永不归零 | 代码复核 |
| 导出大图时点一下没反应 | `toBlob` 失败回调给 `null`，`blob.size` 与 `createObjectURL(null)` 连抛两次 | 代码复核 |
| 局部光控制点的四个滑杆落在卡片外 | `api.el` 的子节点在卡片建好前就求值，滑杆被挂到了外层容器 | 代码复核 |
| 浅色模式下检查器里输入框是黑底 | `dialog/.inspector/.toast` 的 elevated 深色令牌没限定 `[data-theme="dark"]`，浅色下 `--bg` 被抬成 rgb(28,28,30) | 1440 浅色截图肉眼复核 |

```bash
tools/reference/skyfield_check.py 的取数环境见 docs/数据来源与许可.md
```
