# 迭代总览

一页看完这个仓发过什么、每轮动了什么。细证据不在这里，在 `验证记录.md` 与 `发布检查.md`。

## 版本

| 版本 | 日期 | 内容 | 发布物 |
| --- | --- | --- | --- |
| v1.0.0 | 2026-10-19 | 首版：工作台 / 路书 / 星野 / 精修 / 工具箱五个视图；历算与影像算子双套核对；发布自检门禁；同日定名 **Chastar**（初版曾用 Mizar）并配品牌标；同日两轮发布前复检修掉 35 个缺陷 | tag `v1.0.0` + zip 分发包 + GitHub Pages |

tag 与分发包同源：`v1.0.0` 每次重打资产都会把 tag 前移到同一提交，否则"名为 v1.0.0 的包不是 v1.0.0 那个 commit 的产物"——这是评委一眼能查的硬伤，留过一次性检查。

## 每轮动作链

| 轮次 | 触发 | 做了什么 | 验收 |
| --- | --- | --- | --- |
| 1 | 首版落地 | 五个视图、历算核心、影像管线、数据与文档 | `check.sh` 全绿，浏览器肉眼过一遍 |
| 2 | 发布检查发现两处小问题 | 精修面板套预设崩溃、笔刷半径滑杆显示 0 | 影像测试 + 浏览器复核 |
| 3 | 深色模式复核 | 卡片表面改走 `--surface` 令牌；光段刻度按真实时刻定位；参数抽屉给关闭口；画布支持继续拖片 | 浏览器截图 |
| 4 | 打包 | 新增 `tools/package.sh` 出可双击的 zip；自检脚本按码位拦装饰符号 | zip 解开可跑 |
| 5 | 界面层失去人工验证手段 | 新增 `tools/shot.mjs` 无头 Electron 回归并挂进 `check.sh`；修掉它抓出的三处（主题不跟随系统、光段刻度压字、取景投影顶端标签糊成一团） | 17 组全过；zip 解开后以 `file://` 复跑全过 |
| 6 | 命名与图标 | 对外定名 **Chastar**（自造词，中文仍叫光野；初版曾用 Mizar，同日按口味改掉），品牌标几何单源、favicon 另出一版、`apple-touch-icon` 出满幅版交给 iOS 裁 | 明暗截图肉眼复核 + favicon 在 16/32/64px 双底色出图看过 |
| 7 | **发布前两轮全面复检** | 四条并行审：代码缺陷、文档声明一致性、公开面与 git 历史、界面视觉；第二轮换角度复查修复本身、文案、键盘可用性与状态机。两轮合计 **35 个缺陷**（第一轮 23 + 第二轮 12，其中 6 个高危：月末整晚零采样、裁剪后画面平移、裁剪导出底部纯黑带、纹理其实是亮度滑杆、模糊核不对称、悬停银心每帧抛异常；另有门禁自身 3 处失灵、许可面 2 处，都算在这 35 里），外加 8 处文档口径修正 | 每个缺陷各补一条断言或一道门禁；`check.sh` 新增"门禁自测"；历算 336 项、影像 65 项、界面 17 组全绿；解包目录里跑 check.sh 也全绿 |
