# 像素蛋糕功能拆解

拆解对象：像素蛋糕（厦门真景科技，官网 pixcakeai.com，大模型备案 Fujian-FangTang）。
拆解口径：官网产品页、桌面版手册、10.0 更新日志、官方 wiki 的故障说明页、下载接口返回的包体信息，以及评测与投诉文本。
**没有做二进制逆向**：Mac 通用包 2.64 GB、Apple 芯片包 2.59 GB，本机未安装，为了一个参赛作品去拉 2.6 GB 安装包并跑静态分析不划算，而且能拿到的也只是壳，模型权重拿不到。功能与交互层面的拆解靠上面这些一手文字材料，足够支撑我们做取舍。

## 它的功能面

| 层 | 内容 |
| --- | --- |
| 组织 | 项目制；图库 / 精修 / 创意三页签；左侧主页·AI 工具箱·本地项目·云空间·工作流·选片交付·回收站 |
| 驱动方式 | 人物属性驱动：男 / 女 / 儿童 / 长辈男 / 长辈女 / 单人，可改判年龄性别、增删人脸；单人效果能批量同步但不进预设 |
| 皮肤 | 中性灰平整与立体、质感磨皮、高低频磨皮（脸部与身体分开）、水润磨皮、锁骨增强、面部丰盈（额头/面中/面颊/鼻基底/眼窝/眉弓/下巴/嘴角定点） |
| 祛瑕 | 祛斑祛痘（含"质感保留"第三滑杆）、祛痣、祛油光、祛汗珠、祛黑眼圈、祛眼袋（保留卧蚕）、祛双下巴（配阴影量）、面部祛纹按部位左右分开、身体瑕疵分成人/儿童/婴幼儿档 |
| 色彩 | AI 校准白平衡与曝光、多人肤色统一（以最亮脸为参考）、多图色彩统一、AI 追色、色阶曲线 HSL 色彩编辑器颜色分级可选颜色细节颗粒镜头透视矫正校准、直方图带 RGB 与 Lab 读数 |
| 蒙版 | 主体蒙版细分到面部皮肤/脖子/眉毛/眼白/眼瞳/嘴唇/牙齿/口腔/头发/衣服；背景蒙版分天空/草地/水面/沙滩/山川/建筑 |
| 批量 | `Cmd/Ctrl+C` 同步到选中图，弹窗按一级二级勾选；预设分色彩/AI 色彩/人像/组合四类，同类后套覆盖、异类叠加 |
| 工作流 | 内测的节点画布：监听文件夹或 ERP 拉单 → 建项目 → AI 追色 → 套预设 → AI 挑图 → 标签分桶 → 导出回传，每个节点带失败中止/跳过/保留三种错误策略 |
| 输出 | 全链路 16 bit + ProPhoto 内部色空间宣称；导入 `.xmp` 与 `.cube`；导出仅原始格式/JPG/TIFF，sRGB 是"可选转换"；桌面端不能导 RAW |

计费是**按成功导出张数**：预览不扣、原图导出不扣、同图跨设备只扣一次；套餐 299 元 800 张到 18800 元 9 万张，约 0.21–0.37 元/张，有效期一年到期作废。2025-09-22 起基础调色与手动工具永久免费。

## 被专业用户判负的地方

1. 调色与 AI 追色的口碑：常见说法是"颜色很浮""仿色不准"，主流流程是 Capture One / Lightroom 调完色只丢进来修皮肤。
2. 额度一年作废：黑猫投诉二十余起，集中在取消续订无提示、套餐清零。
3. 数据事故：8.30 版本"删云项目连带删本地项目"缺陷导致丢片；清缓存会清掉手动液化与涂抹记录（手动操作不持久化）。
4. 静默置灰：侧身时对称液化置灰、未检测到腿时长腿置灰、天空占比小换天空置灰、内存不足时"同步后不出效果"。原因写在 wiki 里，但界面上不解释。
5. 单人调色与人像效果不进预设、不上云；切 AI 风格会清空所有蒙版。

## 我们抄了什么

| 抄的点 | 在光野里的样子 |
| --- | --- |
| 三层参数结构 | 面板分组 → 功能滑杆 → 子滑杆，滑杆都带单位与口径说明 |
| 高低频磨皮 | `freqSeparationSmooth()`：低频大半径模糊 + 高频回添，边缘用自标定的梯度权重保护 |
| 质感保留 | 独立"质感保留"滑杆（对应它的祛痘三滑杆思路），不是把磨皮一键拉满 |
| 祛油光 | 肤色掩膜 ∩ 高光掩膜，把亮度收向局部均值并回补饱和 |
| 部位化打点 | 亮眼/白牙/黑眼圈/轮廓收扩，由用户点位置——我们没有关键点模型，就不假装知道眼睛在哪 |
| 预设四类 | 五个预设只写参数，不覆盖用户已打的点 |
| 批量同步 | "套用到全部" + 逐张仍可微调 + 逐张导出 |
| 导入 `.cube` | 我们反向做：把色彩链烘成 `.cube` 交给 Lightroom |

## 我们故意不抄的

| 不抄 | 原因 |
| --- | --- |
| 按张计费与强制登录 | 参赛作品不需要，而且这是口碑最差的一环 |
| 云端创意工具（AI 布景、补草地、换天空） | 需要生成式模型与服务器，前端做不了真东西，做假的没意义 |
| 语义分区蒙版（眼瞳/嘴唇/牙齿自动选中） | 要分割网络。我们给判据 + 手动补画，并在界面上说明这是两条腿 |
| RAW 全链路 16 bit | 需要解码器与更大内存模型，v1 只做 8 bit 输入，色深限制在文档里写明 |
| 面部重塑/液化预设 | 没有关键点时"一键瘦脸"是在赌，且这类功能正是"AI 痕迹"和口碑争议最集中的地方 |

## 参照系为什么不止它

主打旅拍与风光，光参考像素蛋糕会跑偏——它本质是人像批产工具。我们另外参照了三家：

- **Evoto**：与像素蛋糕同构（滑杆 + 批量 + 积分），但换天、背景连续性与 AI 挑图更成体系。学它"端上跑 + 逐图自适应 + 点数明示"，避它"积分黑箱 + 预览水印"。
- **Nik Collection / Luminar Neo**：风光真正的差异化在 U-Point 控制点局部调整、分色重明度、结构去雾与分层重打光。光野的"局部光（控制点）"就是 U-Point 的直译实现。
- **Retouch4me**：离线、无账号、买断、单能力极窄。它是"不需要登录也能干活"这条底线的样板。
