# 数据来源与许可

本仓库的代码用 MIT（见 LICENSE）。以下第三方内容各有各的许可，逐条列清楚，方便评委与后来人直接核。

## 恒星表

| 项 | 内容 |
| --- | --- |
| 原始数据 | Yale Bright Star Catalogue 第 5 版（YBS C5），9110 条 V ≤ 6.5 的记录 |
| 取用形式 | `brettonw/YaleBrightStarCatalog` 整理的 `bsc5.json`（4 398 259 B）与 `starNames-IAU.txt`（6 903 B） |
| 许可 | MIT（Bretton Wade, 2016），许可原文保留在 `tools/vendor/LICENSE-brettonw-YaleBrightStarCatalog` |
| 用了什么 | 赤经赤纬（J2000）、视星等、B−V 色指数、HR 编号、拜耳/弗氏命名；IAU 专名 298 条 |
| 生成物 | `src/data/stars.js`（V ≤ 5.6，3249 颗，103 KB），由 `node tools/build-stars.js` 生成，头部注释写明来源 |
| 重新取数 | `bash tools/fetch-data.sh && node tools/build-stars.js` |

原始 `bsc5.json` 4.4 MB，不入库（`.gitignore` 已排除 `tools/vendor/`），需要重建时按上面命令拉。

## 天文算法

| 内容 | 来源 | 许可状态 |
| --- | --- | --- |
| 太阳、月球与五行星的轨道要素与摄动项 | Paul Schlyter，*How to compute the orbital positions of the Sun, Moon and planets*（stjarnhimlen.se/comp/ppcomp.html） | 作者公开提供的教程，数值按原文逐条抄录；本仓库自己实现，未复制其代码 |
| 格林尼治恒星时 | Meeus《Astronomical Algorithms》式 12.2 的多项式（天文年历通行式） | 公式本身不受版权保护 |
| 大气折射 | Bennett (1982) 表达式 | 同上 |
| 银道坐标常数 | IAU 1958 银道系：银极 α=192.859481° δ=+27.128251°，银心 α=266.4051° δ=−28.9362°，北黄极银经 122.931919° | 国际天文学联合会定义 |
| 岁差 | 黄道总岁进动 1.3968138°/世纪（5029″/年） | 常数 |
| 去雾 | He 等人的暗通道先验（CVPR 2009）思路的简化实现 | 算法思想，非代码移植 |

## 参照件与验证

| 内容 | 来源 |
| --- | --- |
| `tests/fixtures/de440s.json` | 用 Skyfield 1.55 + NASA JPL DE440s 行星历表取样生成（`tools/reference/skyfield_check.py`）。DE440s 由 NASA 发布，公开可用；`.bsp` 本体 2.1 MB 不入库，由 Skyfield 自动下载 |

## 界面

| 内容 | 来源 |
| --- | --- |
| 字体栈 | 系统字体（`-apple-system` → SF Pro / PingFang SC），不分发任何字体文件。Apple 官方字体授权不允许随应用再分发，所以界面只写 font-family |
| 数值规范 | Apple Human Interface Guidelines 的 Typography / Color / Materials / Dark Mode / Layout / Motion 六页 |
| 图标 | 界面图标全部为本仓库手写的内联 SVG 线条图标，不使用 SF Symbols 字体或素材（SF Symbols 许可不允许这样用）。品牌标（`assets/icons/`）同样是手写几何：主星四角闪光 + 伴星 + 地平线弧，几何只在 `mark.svg` 存一份，侧栏用 CSS mask 引它；PNG 由 `electron tools/make-icon.mjs` 从 `mizar.svg` 栅格化，不引入任何图标库或位图素材 |
| 名称 | Mizar 与 Alcor 是恒星的传统专名（拜耳命名 ζ UMa / 80 UMa），专名本身不构成可商标的素材；本项目的标与字体排布均为原创 |
| 星群连线 | `src/data/asterisms.js` 手写，端点用拜耳键指认，生成时强制回查星表，查不到直接报错退出 |
