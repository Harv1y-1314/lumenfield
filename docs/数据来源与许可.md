## 恒星表

| 项 | 内容 |
| --- | --- |
| 星表本体 | Yale Bright Star Catalogue 第 5 版（Hoffleit & Jaschek, 1991；Yale University Observatory 发布，经 NASA ADC / VizieR 分发）。本次取用的 `bsc5.json` 实测 **9096 条记录**；本仓只取其中 V ≤ 5.6 的 3249 条 |
| 取用形式 | `brettonw/YaleBrightStarCatalog` 整理的 `bsc5.json`（4 398 259 B）与 `starNames-IAU.txt`（6 903 B） |
| 许可（分两层，别混） | **封装** = MIT（Copyright (c) 2016 Bretton Wade），正文随仓分发在 `THIRD_PARTY_NOTICES/brettonw-YaleBrightStarCatalog-MIT.txt`；**星表本体** = 已发表的实测数据集，历史上未附开放条款，通行做法是自由使用 + 请求引用，本仓不主张对它拥有版权，也不主张 MIT 覆盖了它。两层口径见 `THIRD_PARTY_NOTICES/README.md` |
| 引用 | Hoffleit, D.; Jaschek, C., *The Bright Star Catalogue*, 5th revised edition, Yale University Observatory, 1991 |
| 用了什么 | 赤经赤纬（J2000）、视星等、B−V 色指数、HR 编号、拜耳/弗氏命名；IAU 专名匹配 300/312 条，生成物里最终落 298 个（差额是 V>5.6 被星等阈值剔掉的星，注释与文档的口径差在这里） |
| 生成物 | `src/data/stars.js`（V ≤ 5.6，3249 颗，103 KB），由 `node tools/build-stars.js` 生成，头部注释写明来源 |
| 重新取数 | `bash tools/fetch-data.sh && node tools/build-stars.js`（当前重跑逐字节可复现，只有头部注释会变） |

原始 `bsc5.json` 4.4 MB 与其中转折射是生成输入，整目录被 `.gitignore` 的 `tools/vendor/` 挡掉不入库——**许可正文不在这个目录里**，它必须随仓分发，所以在 `THIRD_PARTY_NOTICES/`。

## 拍摄地预设（`src/data/sites.js`，40 个点）

| 项 | 内容 |
| --- | --- |
| 来源 | **自编**：每个点取公开景区或成熟机位的中心坐标，海拔取该处公开标注值，时区取所在国现行偏移。不是从任何数据集抄来的 |
| 许可 | 无第三方许可问题；但**没有精度承诺**——是"给一个起点"，不是"精确到米的机位"，界面允许就地手改 |
| 自检 | 文件尾部算 `problems`（境内框、经纬颠倒、时区越界）。界面上不显示，所以由 `tests/astro.test.mjs` 挂一条断言当消费者：手写错一个点，测试当场红 |
| 口径提醒 | 其中"光污染极低（Bortle 1–2）"一类描述是**主观估计**，与"算不出来的东西不假装能算"这条一致——真实测量一律标自填 |

## 界面

| 内容 | 来源 |
| --- | --- |
| 字体栈 | 系统字体（`-apple-system` → SF Pro / PingFang SC），不分发任何字体文件。Apple 官方字体授权不允许随应用再分发，所以界面只写 font-family |
| 数值规范 | Apple Human Interface Guidelines 的 Typography / Color / Materials / Dark Mode / Layout / Motion 六页 |
| 图标 | 界面图标全部为本仓库手写的内联 SVG 线条图标，不使用 SF Symbols 字体或素材（SF Symbols 许可不允许这样用）。品牌标（`assets/icons/`）同样是手写几何：主星四角闪光 + 伴星 + 地平线弧，几何只在 `mark.svg` 存一份，侧栏用 CSS mask 引它；PNG 由 `electron tools/make-icon.mjs` 从 `mizar.svg` 栅格化，不引入任何图标库或位图素材 |
| 名称 | Mizar 与 Alcor 是恒星的传统专名（拜耳命名 ζ UMa / 80 UMa），专名本身不构成可商标的素材；本项目的标与字体排布均为原创 |
| 星群连线 | `src/data/asterisms.js` 手写，端点用拜耳键指认，生成时强制回查星表，查不到直接报错退出 |
