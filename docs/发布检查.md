# 发布检查

上传公网前后逐项过的清单。能机器判定的都在 `tools/check.sh` 里，这一页记结论与判不了的部分。

## 一、AI 痕迹

| 检查 | 结果 |
| --- | --- |
| 模板腔与营销词 | 无"极致体验/一键大片/赋能"类表述；界面文案统一按摄影师口径写（到场时间、-0.833° 为升落） |
| 装饰性符号 | 无装饰性 emoji。判据是 check.sh 里按 Unicode 码位扫的 11 个常用装饰符号，**连 check.sh 自己一起扫**——上一版把符号写进黑名单又把自己摘出去，"全仓零 emoji"这句话自己就不成立。界面里的 `▶`/`‖` 是功能字形（播放与暂停），判据不把它们当装饰 |
| 待办与占位标记 | 零残留；砍掉的功能都写成"未做 + 原因"，不留空壳 |
| 假数据 | 无。云量、空气通透度、Bortle 光污染在界面上明确标"自填/需联网"，不填假值。文档里也不许声称有界面没有的字段——"视宁度自填"就是这样被复检抓出来删掉的（六个文件同时超售，含界面弹窗） |
| 注释与提交口吻 | 注释解释"为什么这样做"和"上次怎么错的"，不复述代码；提交信息只讲改动与根因，不写开发工具、不写"等人回来"这类过程口吻 |

不假装开发方式，也不主动标榜：仓库里没有关于开发工具的表述，代码与文档按普通工程件的标准自查。

| 项 | 结果 |
| --- | --- |
| 本机用户名 | 零命中（现取 `id -un`，不写死） |

| 内网面 | 零命中。只判形状确定的私有网段、本机主机名与 ssh 目录；裸 `10.x` 与 `.local` 因会撞版本号与 `p.local` 这类属性名而**刻意不收**——判不准的规则留着只会让人学会忽略它 |

| 手机号样式数字 | 零命中；判据按号段而不是任意 11 位数字，避免误伤天文常数 |

| 大文件 | 无 >1.2 MB；4.4 MB 的原始星表整目录 `.gitignore`，只入库生成物与生成脚本 |
| 截图内容 | 十张截图均为界面本身，无个人照片、无文件名泄露（精修页样片是脚本现画的纯色渐变，不是真实人像）；PNG 元数据逐张查过，无 EXIF、无作者机名 |
| 历史 | 全历史逐 blob 扫过（数量随提交增长，本页不写死）：绝对路径/真实姓名/令牌/私钥/私有项目名零命中；reflog 无 force-push 与 amend，公网可见内容 = 已扫内容 |

## 三、漏洞面

| 面 | 结论 |
| --- | --- |
| 运行期网络 | 零请求：无 fetch、无 XHR、无外链脚本、无 CDN、无 Worker。用户照片只在内存与本地 canvas 之间流动 |
| 第三方依赖 | 零依赖（无 package.json、无 node_modules）→ 没有供应链面 |
| 字符串求值 | 无 `eval`、无 `new Function`、无 `document.write`、无 `insertAdjacentHTML`。**这条判据曾经失明**：模式被写成 `e''val\(`，正则匹配的是字面 `e''val(`，塞进真 `eval(` 也报 ok。现在 check.sh 有一道"门禁自测"——现场造一个含 `eval(` 的探针文件，抓不到就整体 FAIL |
| 注入面 | `innerHTML` 仅 2 处，喂的都是仓内写死的 SVG 图标常量；所有用户可见文本走 `textContent` 与 `createTextNode` |
| 文件输入 | 只接受 `image/*`，读入即 `FileReader → Image → canvas`，不落盘、不上传；解码失败与尺寸无效都给可读提示，不再静默卡住整批 |
| 存储 | `localStorage` 读写全部 try/catch 包裹，file:// 与隐私模式下降级为内存态；读回来时**关键量程**（时间轴 12–30、焦距、方位、中心高度、星等上限、路书天数、自定义站点经纬与时区）都过 `isFinite` 并夹回范围，播放态一律不恢复 |
| CSP | 故意没加。加 `script-src 'self'` 会威胁"双击 index.html 就能用"这条底线（file:// 下 CSP 对本地脚本的判定在各浏览器不一致），而本站既无外部脚本也无用户输入回显，收益为零。若日后只做 Pages 部署，可以在托管层加响应头，比写在 meta 里稳 |
| 已知限制 | 8 bit 输入色深；无 RAW 解码；星图岁差用总岁进动近似（不含章动，误差 <0.01°）；镜头视场投影在 >60° 视场时形状畸变到 3% 量级；全尺寸导出是主线程同步计算（24MP 实测约 40 秒），导出面板给长边上限自调，界面会先把目标尺寸报出来 |

## 五、界面

界面回归由 `tools/shot.mjs` 代跑：无头 Electron 加载 `file://`，改系统明暗偏好来验"跟随系统"这条路，逐组截图并探测四件事——兜底卡有没有出现、控制台有没有报错、画布有没有真的画出亮像素、页面有没有横向溢出。

17 组的构成：五个视图 × 明暗 × 1440（10 组，其中 5 个星野组各在画布上扫 30 个悬停点，走 hitTest 与 tooltip 这条纯鼠标路径）、首页/星图/精修 × 412（3 组）、路书 × 900（1 组）、精修拖放导入并断言调参前后像素哈希必须变化（1 组）、星野穹顶与取景两套投影 × 明暗（2 组）。当前 **17 组全过，0 失败**。

复检抓出并回修的界面问题（只列这一轮新增的，历史条目在 `docs/验证记录.md` 那张表）：

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 浅色模式下检查器里的输入框是黑底 | `dialog/.inspector/.toast` 的 elevated 深色令牌没限定 `[data-theme="dark"]`，浅色下 `--bg` 被抬成近黑 | 令牌限定到深色；这条以前只能靠肉眼，现在 1440 浅色截图必须过一遍眼 |
| 浅色模式下"一天里的光路"几乎看不见 | 直接抄了星图那套"深底浅字"的硬编码色，而这张图坐在白卡片里 | 网格与标签按 `data-theme` 分两套，底色取卡片自己的 `--surface` |
| 夏夜把指针移到银心光带上就每帧抛 TypeError | 银心标记只带屏幕坐标进 `bodies`，`hitTest` 仍当它是可悬停天体 | hitTest 只收带 alt/az 的天体；回归加悬停扫描 |
| 局部光控制点的四个滑杆跑到卡片外面 | `api.el` 的子节点在卡片节点建好之前就被求值，滑杆挂到了外层容器 | 先建卡片再往里挂 |
| 播放中碰任何一个滑杆，时间轴冻住但按钮还显示暂停 | 播放帧与重绘帧共用一个 `raf` 句柄 | 两个句柄分开 |
| 中途关页面后下次打开自动开播、白烧 CPU | `playing` 是运行态却被持久化，切走时只改内存不落盘 | `_cleanup` 里停掉并落盘；`load()` 永不恢复播放态 |
| 工作台用久了拖窗口开始卡 | 每次渲染都 `+1` 个 window 级 resize 监听，旧闭包钉住整批 DOM 节点 | 补 `_cleanup` 摘监听 |
| 手改进度坐标刷新即丢，侧栏下拉还空白 | 自定义站点从没入库，`siteFromKey('custom')` 找不到就退回第一个预设 | 存档补 `custom` 字段并做类型校验；下拉补"自定义机位"这一项 |
| 日期串读不出顺序 | `A.fmt` 输出"日 月 时:分" | 改 `MM-DD HH:MM` |

**仍待人工确认两项**：精修页一次导出多张时浏览器"允许下载多个文件"的放行提示（宿主行为，页面拿不到被拦截的回调；代码侧已改成等上一张真的算完再排下一张、每张 toast 报进度、结束报总张数）；iPhone Safari 真机排版（桌面 412px 与断点已由回归覆盖，触控拖拽与存储配额需实测）。
